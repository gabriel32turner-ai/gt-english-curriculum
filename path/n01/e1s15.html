Grammar · Is there…? Are there…?

14–25 min · Discover → understand → practice
Questions + short answersGRM-15 Tic-Tac-Toe
Discover

Paola is new. She asks a neighbor. Find the questions.

(Respuesta: Is there + una cosa · Are there + varias · respuesta corta: Yes, there is / No, there isn't)
The tool

The question flipper · statement ⇄ question

one = Is there a…? · two or more = Are there …s?
?Is there a bank near here? Are there good cafés?
+Yes, there is. / Yes, there are.  + location: It's next to the park.
−No, there isn't. / No, there aren't.
Is‿there…? ↗Are‿there…? ↗No, there isn't. ↘

¿Hay…? Se voltea el orden: There is → Is there…? (una cosa) · There are → Are there…? (varias).

Respuesta corta: Yes, there is. / No, there isn't. — Yes, there are. / No, there aren't. No se contesta solo “Yes” ni “Yes, it is”.

Ojo: “¿Hay un banco cerca?” = Is there a bank near here? — no “Have a bank?” ni “There is a bank?”.

Bonus: después de “Yes, there is”, di dónde: It's next to the park. (S14).
