Grammar · Some / Any

13–25 min · Discover → understand → bet
New pointGRM-16 Mystery Box · apuesta
Discover

Read the chat. When do we say SOME, and when ANY?

🧊🥛

Is there any milk?

Yes, there's some milk. But there isn't any cheese.

Do we have any eggs?

Yes, we have some. We don't have any bread, though.

Count them. How many do you see?(Respuesta: 6 · any milk, some milk, any cheese, any eggs, some, any bread)
The tool

some = affirmative · any = negative and question

1 · Affirmative (+)

some + noun

We have some rice. There is some milk. There are some eggs.

2 · Negative (−) / Question (?)

any + noun

We don't have any bread. Is there any milk?

3 · Countable & uncountable

some/any + plural or uncountable

some eggs (plural) · some milk (uncountable, no plural).

Examples
+ AffirmativeWe have some rice. There is some milk. There are some eggs.
− NegativeWe don't have any bread. There isn't any cheese. There aren't any tomatoes.
? QuestionDo we have any eggs? Is there any milk? Are there any apples?

Afirmativo: some + sustantivo. Negativo y pregunta: any + sustantivo. Con contables en plural: some/any eggs. Con incontables: some/any milk.

¿Qué es? Some = algo de/unos (afirmativo). Any = nada de/algún (negativo y pregunta).

¿Cómo se usa? Con afirmativo: some (We have some rice). Con negativo y pregunta: any (We don't have any bread. / Do we have any eggs?). Se usan con contables en plural (some eggs) y con incontables (some milk).

¿Cómo suena? Some se pronuncia /sʌm/, rápido y sin acentuar. Any se pronuncia /ˈeni/. Los plurales -s de eggs y tomatoes terminan en el sonido /z/.

¿Para qué hoy? Para decir qué hay y qué no hay en tu refri antes de decidir si cocinas o pides comida — lo vas a usar en la Mission de hoy.

Practice A · Mechanical

Choose: some · any

Practice B · GRM-16

Mystery Box — bet, ask correctly, open the box

1. The box is the inside of a fridge — you can't see it yet. 2. Bet 1, 2 or 3 points that the food IS there. 3. Ask with the correct form (Is there any…? / Are there any…?) — only a correct question opens the box.

Points: 0
Watch out

Mistakes at this level

Is there some milk?Is there any milk?In a question we use any, not some.
We have any rice.We have some rice.In the affirmative we use some, not any.
There isn't some cheese.There isn't any cheese.In the negative we use any, not some.
Teacher notes · §3 Grammar

Pedagógica

  • Punto NUEVO del día. Da tiempo real al Discover antes de nombrar la regla. Practice A es mecánica (máx. 1/3 del bloque).
  • Mystery Box es APUESTA: el alumno arriesga puntos antes de saber la respuesta — el riesgo real es lo que sostiene la atención, no la velocidad. Solo una pregunta BIEN FORMADA abre la caja; si pregunta mal, puede reintentar sin perder el punto apostado.
  • Nivel: sin much/many (eso es S22) y sin a lot of/a few/a little (eso es S23). Sin ofertas con some ("Would you like some…?" fuera del nivel).

Engagement

  • "Bet smart — can you open all 6 boxes and keep your points?"

Crecimiento

  • Some/any regresa en S22 (how much/how many) y S23 (a lot of/a few/a little).

Pronunciation

Teacher notes · §5 Listening

Pedagógica

  • Guion de 2 hablantes, para grabar: ANA (mujer, Irish English, lenta) y DAN (hombre, US English, lento) — personajes NUEVOS del nivel.
  • Answer key — Global: (a) checking the fridge. Las 3 diferencias: audio dice "no cheese" (imagen muestra cheese) · audio dice "some eggs" (imagen muestra sin eggs) · audio dice "no bread" (imagen muestra bread). Milk, tomatoes y rice NO son diferencias — coinciden en ambos.
  • La imagen fija nunca cambia; solo el audio revela las contradicciones.

Engagement

  • "The picture never lies — but does it match what Ana and Dan say?"

Crecimiento

  • Las palabras del guion (milk, cheese, eggs, bread, tomatoes, rice) regresan en la Mission.

Pedagógica
